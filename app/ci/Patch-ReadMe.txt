视频工作台 Windows 版 · 升级补丁
================================

已经解压过完整包（7.8GB 那个）的电脑，用这个补丁就能升级到最新版，不用重新下载完整包。
不管之前是哪个版本，直接用最新的补丁覆盖就行。

【怎么用】
1. 先把「视频工作台」关掉。
2. 把这个补丁解压，里面有一个 resources 文件夹。
3. 把这个 resources 文件夹拖到软件所在的文件夹里（和 VideoWorkbench.exe 放一起），
   Windows 问「是否替换」时选「替换目标中的文件」。
4. 重新打开软件，右下角的版本号变成补丁文件名里的版本号，就是装好了。

【v0.1.2 改了什么】
- 字幕识别换成快速识别（SenseVoice 小模型）：不用显卡，比原来快很多，中文更准。
  设置 → 识别引擎 可以改回原来的 Whisper。
- 数字人提速：贴图、换背景、编码改成和显卡同时进行。
- 数字人新增「快速模式」（设置 → 数字人，默认关闭）：速度明显更快，嘴部细节会略软一点，
  建议先用同一段素材开、关各生成一条，对比后再决定要不要常开。
- 没有显卡硬件编码的电脑，字幕烧录的编码更快。

【v0.1.1 改了什么】
- 软件放在带中文的文件夹里时，字幕识别（转文字、字幕烧录）会崩溃 —— 已修好。
- 数字人任务一直显示「准备中」、进度不动 —— 已修好，现在会显示进度和每秒帧数。
- 数字人降低显存占用：8GB、6GB 显存的显卡更不容易被挤满；显存不够时会自动减量重试，而不是直接失败。
- 数字人每条任务会在「_原片」文件夹里留一份 .log 运行记录。
