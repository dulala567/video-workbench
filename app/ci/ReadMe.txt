视频工作台 Windows 版
====================

【怎么打开】
1. 把整个压缩包解压到一个文件夹（不要在压缩包里直接双击运行）。
2. 双击文件夹里的 VideoWorkbench.exe。
3. 第一次打开如果弹出「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。
   （软件没有做微软付费签名，所以会有这个提示，之后就不会再弹。）

【能做什么】
- 字幕烧录：自动识别视频里的语音，把字幕（可选样式、标题、滤镜）烧进视频。
- 转文字：视频/音频转成文字稿，可导出 SRT 字幕。
- AI 配音：豆包语音合成，文案一键配成音频，带逐字字幕；也能用「音频生成 1.0」一段提示词生成带配乐音效的音频。
  需要你自己的豆包语音 API Key（火山引擎控制台 → 豆包语音 → API Key 管理），在 AI 配音页填写。
- 音频提取：从视频里提取音频，MP3 / M4A / WAV / FLAC，或原样复制音轨。
- 数字人口型：一张照片或一段人像视频 + 一段音频，生成对口型的口播视频，可换背景、加背景音乐和字幕。
  需要 NVIDIA 显卡（建议显存 6GB 以上，显卡驱动尽量更新到最新）。
  没有 NVIDIA 显卡也能用，但会用 CPU 算，非常慢。设置 → 检测环境 可以看有没有识别到显卡。
- 采集中心、发布到账号。

【文件存在哪】
默认在「视频」文件夹下的「视频工作台」里，设置里可以改。

【电脑要求】
Windows 10 / 11，64 位。解压后约占 10GB 左右硬盘。
解压位置的路径别太深（比如直接放 D:\视频工作台），路径太长 Windows 可能解压出错。有 NVIDIA / Intel / AMD 显卡硬件编码时会自动用上，没有也能用（会慢一些）。
所有处理都在本机完成；只有 AI 配音会把文案发给豆包。
