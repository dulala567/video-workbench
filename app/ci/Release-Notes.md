视频工作台 Windows 版 v__VER__。字幕识别烧录、AI 配音、音频提取、数字人对口型，全部在自己电脑上运行。

## 下载哪个

| 情况 | 下载 |
|---|---|
| 第一次装 | 下面 Assets 里全部 `VideoWorkbench-Windows-x64-v__VER__.zip.001`、`.002`……（共 __PARTS__ 个，合计约 __SIZE__GB） |
| 已经装过完整包（v0.1.0 起），只想升级 | 只下 `VideoWorkbench-patch-v__VER__.zip`（约 __PATCH__MB） |

GitHub 单个文件最大 2GB，所以完整包拆成了几份。

## 第一次装

1. 把 `.001`、`.002`…… 全部下载到**同一个文件夹**，一个都不能少。
2. 装 [7-Zip](https://www.7-zip.org/)（免费）。Windows 自带的解压认不出分卷文件。
3. 右键 `.zip.001` → 7-Zip → 提取到……，选一个**浅的路径**，比如 `D:\视频工作台`。路径太深 Windows 可能解压出错。
4. 打开解压出来的文件夹，双击 `VideoWorkbench.exe`。第一次如果弹出「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」（软件没有做付费签名）。

解压后约占 10GB 硬盘。文件夹里的 `ReadMe.txt` 有完整说明。

## 升级

先关掉软件，再解压补丁，把里面的 `resources` 文件夹拖进软件文件夹（和 `VideoWorkbench.exe` 同一层），选「替换」。重新打开后右下角显示 v__VER__ 就是升级成功了。

## 电脑要求

- Windows 10 / 11，64 位。
- 数字人对口型要 NVIDIA 显卡：RTX 20 / 30 / 40 / 50 系，建议显存 6GB 以上，驱动更新到最新。没有 NVIDIA 显卡也能打开，但数字人会用 CPU 算，非常慢；其他功能不受影响。
- AI 配音要你自己的豆包语音 API Key。

## 这一版

- 字幕识别换成 SenseVoice 小模型，不用显卡，比原来快约 10 倍；设置 → 识别引擎 可以换回 Whisper。
- 数字人生成提速；新增「快速模式」（设置 → 数字人，默认关，更快但嘴部略软）。
- 降低显存占用，显存不够时自动减小批量重试。
- 修复：软件放在中文文件夹里识别报错；数字人一直停在「准备中」。

在 NVIDIA 显卡上的实际速度还没有在真机上测过。遇到问题请到 [Issues](https://github.com/dulala567/video-workbench/issues) 反馈，数字人的问题请附上输出文件夹「_原片」里的 `.log` 文件。

## 校验

`SHA256SUMS.txt` 里是每个文件的 SHA-256，可以用 PowerShell 的 `Get-FileHash 文件名` 对照。
